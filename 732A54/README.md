# 732A54 Big Data Analytics

## Course Info
- **Code:** 732A54
- **Name:** Big Data Analytics
- **Term:** 2025 VT

## Summary
This course covers the technologies and methodologies for analyzing large-scale datasets. It focuses on using SQL for data management and Apache Spark for distributed computing. Key topics include Spark Core, Spark SQL for structured data processing, and Spark MLlib for scalable machine learning applications.

## Contents
- Lab 0: SQL
- Lab 1: Spark
- Lab 2: Spark SQL
- Lab 3: Machine Learning
