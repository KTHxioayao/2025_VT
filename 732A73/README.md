# 732A73 Bayesian Learning

## Course Info
- **Code:** 732A73
- **Name:** Bayesian Learning
- **Term:** 2025 VT

## Summary
This course provides a solid foundation in Bayesian statistics and machine learning. It covers the principles of Bayesian inference, including prior and posterior distributions, parameter estimation, and model selection. Practical implementation involves using R and potentially probabilistic programming tools like Stan to solve complex statistical problems.
