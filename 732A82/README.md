# 732A82 Deep Learning

## Course Info
- **Code:** 732A82
- **Name:** Deep Learning
- **Term:** 2025 VT

## Summary
This course offers a comprehensive introduction to deep learning and neural networks. The curriculum is structured to guide students from the fundamentals of Back Propagation to advanced architectures. Key topics include Deep Neural Networks (DNN), Convolutional Neural Networks (CNN) for image data, Recurrent Neural Networks (RNN) for sequential data, and modern Transformer models.

## Contents
- **1. Back Propagation**: Implementation of single and multi-layer networks to understand the mechanics of forward and backward passes.
- **2. DNN**: Practical application of Deep Neural Networks, focusing on architecture design and hyperparameter tuning.
- **3. CNN**: Building and training Convolutional Neural Networks, specialized for image classification and feature extraction.
- **4. RNN**: Working with Recurrent Neural Networks for sequence modeling, applied to text data (e.g., English-Swedish translation).
- **5. Transformers**: Exploring modern Transformer architectures, including Vision Transformers (ViT) for image tasks.
